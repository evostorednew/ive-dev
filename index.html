◐ ROUTE · FOUR PRODUCT PILLARS

The whole run stays in one control plane.

Observe the sessions. Route the work. Close the loop. Carry context forward.

CONTROL / MISSION CONTROL + REAL PTY

See every terminal.

Mission Control keeps model, status and effort visible across the run. Every session is a real PTY through os.fork() + pty.openpty(), rendered in xterm.js with plan mode, slash commands and real keyboard behavior.

Grid, split and tab layouts · session merge · broadcast groups · multi-line composer · force-send

ROUTE / COMMANDER + PIPELINES + BOARD

Turn one objective into scoped work.

Commander starts sessions, assigns tasks and tracks progress. Visual pipelines add stages, conditions and delays. The Feature Board dispatches from Ready by board column, webhook or pipeline completion.

Scoped MCP server · drag-and-drop graph · file-lock detection · sub-agent tree · CLI hooks for lifecycle, tools, spawning and compaction

◇ VERIFY · REVIEW AND INTERVENTION

The human gate stays visible.

Review the diff. Annotate the output. Open the live preview. Catch up before you approve what changed.

Diff review

File tree, inline annotations and one-click feedback to the session. Open the work in VS Code, Cursor or Zed.

Visual intervention

Capture a URL, add rectangles, arrows, text or a Web Speech voice note, then send the annotated screenshot to a session.

Live preview

Use the in-app browser and screenshot capture without switching windows.

Session control

Merge conversations, broadcast a message, use the command palette, inspect plans and configs, clone sessions, import history and manage context compaction.

Prompt system

Build templates and cascades with variable substitution, loops, auto-approval and output styles such as lite, caveman, ultra and dense. Vague-prompt detection suggests alternatives; @research and @prompt:Name expand before send.

Catch-up

Briefings combine events, commits and memory changes. A stale-session banner opens preset or custom ranges; activity stays filterable and access mode controls what a joiner may see.

◐ ROUTE · COMPATIBILITY

Use the supported CLI for the task.

IVE currently supports Claude Code and Gemini CLI. Pick Haiku, Sonnet, Opus, Gemini Pro or Flash per session, and switch models mid-session.

ROADMAP · additional CLIs and models are planned, not supported today

! VERIFY · SECURITY AND DEPLOYMENT

Put controls in the execution path.

Scan before install. Isolate before write. Enforce access before a tool runs. Keep every change in the audit trail.

SUPPLY CHAIN SHIELD

Stop a bad package before it lands.

AVCP intercepts pip, npm and GitHub Actions, then runs the documented package scan.

WORKTREES + CONFLICTS

Keep parallel writes isolated.

Each session gets a git worktree. File locks detect collisions and reroute work before overwrite.

ACCESS MODES

Decide who can approve.

Brief is scoped to tasks and notes. Code drives sessions in auto or plan with Bash allowlisting. Full is owner-equivalent and TTL-bounded.

AUTH AUTOPILOT

Keep account state separated.

Quota events can rotate to the next OAuth account in LRU order. Each account uses a sandboxed HOME so cookies do not cross.

COLLABORATION

Share a tunneled URL, a one-shot four-word invite or a QR token. Invites burn atomically and are rate-limited per IP.

REMOTE CONTROL

Add the PWA to a phone and receive Web Push notifications. Catch-up briefings restore context before intervention.

ENFORCEMENT

Route guards, CLI flag injection and PreToolUse hooks apply the active access mode independently.
